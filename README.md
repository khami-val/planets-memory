# ЕкоСлід Пам'яті: MVP

Статичний сайт без збірки: HTML + CSS + vanilla JS, mobile-first.

## Запуск
Відкрити `index.html` у браузері або: `python3 -m http.server` у цій папці → http://localhost:8000

## Структура
- `index.html`: розмітка (герой, калькулятор, симулятор, порівняння, «Чому це важливо», міфи, методологія)
- `css/styles.css`: стилі (токени кольорів у `:root`)
- `js/data.js`: усі цифри, джерела та припущення. Змінювати дані тут.
- `js/app.js`: логіка калькулятора, SVG-симулятор, таблиця методології

## Дані
CO2e подано діапазонами між джерелами (TNO 2011, Planet Mark 2023, Green Burial Council 2023, Recompose/MIT TR 2020).
Значення з позначкою `assumption: true` є припущеннями моделі й показуються на сайті з тегом «припущення».
